# Cheap domain names

I like learning about niche computing topics. Cheap domain names are a particular area of interest, so I was excited to learn about [1.111B class domains](https://gen.xyz/1111b), described as an “affordable class of .xyz domains made up of 1.111 billion possible [...] numeric combinations, between 000000.xyz through 999999999.xyz”. The renewal fee for 1.111B class domains is very low (around $1.24 per year). As expected, these cheap domains are associated with scam websites and as a result “many or all” .xyz domains have been [blacklisted by anti-malware services](https://en.wikipedia.org/wiki/.xyz#Malicious_domains).
